# 截图占位

README 的界面预览暂时使用文字占位。补充真实截图时放入本目录：

| 文件 | 页面 |
| --- | --- |
| `scan.png` | 扫码页 |
| `confirm.png` | 确认页 |
| `using.png` | 使用中页面 |

建议使用真机截图，宽度 1080 px 左右，保持三张图尺寸一致。截图前请打码：

- 手机号、验证码与 token。
- 订单号、支付单号与金额（如需保留示例金额，请使用测试数据）。
- 设备完整标识、位置与原始 JSON。
- 通知栏中的其他个人信息。

添加图片后，将 `README.md` 中的 HTML 注释替换为实际图片标签，并确认链接可访问。
