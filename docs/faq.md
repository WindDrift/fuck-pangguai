# 常见问题

## 构建与安装

### 编译成功，但登录或扫码一直失败

仓库不提供官方客户端凭据。请检查 `secrets.properties` 或环境变量 `QIEKJ_APP_SECRET` / `QIEKJ_LOCATION_SECRET` 是否已配置，然后重新构建。未配置凭据时，联网功能必然失败。

### 为什么仓库不提供凭据和接口文档

公开凭据会让任何人都能直接复用，增加滥用与合规风险；接口、签名算法和反编译材料也不适合作为公开文档。项目只提供使用与架构说明，构建者需自行准备有权使用的凭据。

### 自行构建的 APK 能覆盖安装 Release 吗

不能。两者签名不同，Android 会拒绝覆盖安装。请先备份需要保留的记录，再卸载旧版本。卸载会删除本机历史。

### 支持哪些 Android 版本

最低 Android 12（API 31）。更低版本未适配，也不在测试范围内。

### 构建时提示找不到 SDK 或 JDK 版本错误

安装 JDK 21 与 Android SDK Platform 37，并检查 `JAVA_HOME`、`local.properties` 或 `ANDROID_HOME`。详见[构建指南](build.md)。

## 登录与权限

### 收不到短信验证码

验证码由官方服务发送。确认手机号格式、网络状态和短信拦截设置；短时间内频繁请求可能被限流。应用不提供绕过验证码的入口。

### 定位权限被拒绝后还能接水吗

不能。确认页需要定位来构造风控参数，拒绝权限或无法取得位置时会阻断。请在系统设置中授予精确定位后重试。

### 为什么需要通知权限

接水过程使用前台服务持续同步状态，通知用于展示进度和结果。拒绝通知权限不会阻止接水，但可能看不到状态提醒。

### 登录过期怎么办

失效账号会被标记为“已失效”，当前账号失效时会回到登录页。登录页会列出本机已保存的账号：可以直接切到其他有效账号，或对失效账号重新验证码登录。失效不会删除该账号的历史；只有删除账号才会删除。若需要撤销服务端会话，请使用官方客户端的注销流程。

### 如何添加或切换账号

点设置页顶部账号卡片右上角的切换账号图标，或在“账号 → 添加账号”中登录另一个手机号。账号按最近使用时间排序，点击有效账号即可切换。接水进行中不允许切换。

### 切换账号后接水历史去哪了

历史按账号隔离。切换后历史页只显示新账号的记录；切回原账号即可看到原记录。导出 CSV 与清空历史也只作用于当前账号。

### 为什么头像不显示

头像地址由官方资料返回。没有头像、地址不是 HTTPS、网络不可用或图片已失效时，应用会显示昵称首字占位。头像请求不携带登录凭证。

### 通用小票的点数怎么换算

`100 点 = 1 元`，即 1 点 = 0.01 元。设置页会同时显示点数和约合金额，并拆分本金与赠送；具体退款规则以官方客户端和店铺说明为准。

### 通用小票充值支持哪些支付方式

当前只支持支付宝。微信、账户余额、一卡通等通道未实现。部分店铺可能未开通支付宝，充值页会禁用“确认充值”并提示不支持。

### 支付成功但小票未到账

客户端以官方服务订单状态为准，不只看支付宝返回的“支付成功”。如果页面显示“支付结果确认中”，请先点击“重新查询”或回到店铺后重新进入充值页查询；不要重复支付。若支付宝已扣款但长时间未到账，请保留订单号并联系官方客服或商家。

### 通用小票充值能退款吗

客户端不提供退款操作，只展示官方返回的退款说明。退款需要联系官方客户端、商家或学校运营方；到账与退款规则以官方为准。

### 支付结果未知怎么办

不要重复支付。应用会保留待确认订单 2 小时，并提供“重新查询”；重新进入充值页也会显示待确认提示。若确认支付宝已扣款，请联系官方客服处理；若未扣款，可在订单关闭后重新下单。

## 设备与接水

### 提示 BLE 设备不支持

当前版本只支持非蓝牙设备。`isBluetooth=1` 的设备会直接阻断，这是已知限制，不是权限或网络问题。

### 提示 4204 或设备故障

这是设备返回的故障状态。请检查设备是否离线、维护中或缺少耗材；应用不会绕过故障继续解锁。

### NFC 标签没有反应

确认系统 NFC 已开启、应用有 NFC 权限，并将手机天线靠近标签。首次使用需要绑定标签；如果映射丢失，重新绑定即可。

### 换了设备或学校后 NFC 不工作

标签格式和映射可能不同。删除旧映射并重新绑定；仍无法识别时改用扫码或手动输入。

### 支付状态一直显示未知

支付查询有超时上限。超时后应用不会自动重试或重复扣款，请回到原 App 或支付渠道核对账单。若已扣款但状态未更新，保留订单号并向官方客服反馈。

### 应用退到后台后接水会中断吗

不会。接水期间会启动前台服务并显示通知。请不要在接水过程中强制停止应用或撤销通知权限。

## 数据与历史

### 接水记录保存在哪里

仅保存在本机 SQLite，不上传。可在历史页查看、删除单条或清空全部记录。账单匹配结果也随记录缓存在本机，删除记录或清空历史时会一并删除。

### 历史里的实付金额怎么来的

历史页会按结算订单号读取官方账单。列表与详情中的“实付”采用官方“实付款”口径，原价、各项优惠、支付优惠和通用小票抵扣只作为明细展示，不会重复从实付中扣减。筛选栏下方的统计卡只汇总当前筛选结果的原价、纯数字用量和同口径平均单价，具体口径见统计卡说明。

### 为什么有些记录显示“未找到对应账单”

可能是订单号尚未同步、官方账单还未生成、账单已超过 90 天自动同步范围，或网络请求失败。记录不会被删除，也不会用本地“用量”冒充金额；可以点“同步账单/刷新账单”重试，或下拉刷新继续同步。较早的记录会在打开详情时按需匹配。

### 为什么小票流水显示未匹配

账单里已有通用小票抵扣时，应用会再查对应店铺的流水来补充本金/赠送和时间。流水可能因分页范围、数据延迟或网络失败而查不到；这时仍会显示账单内的抵扣金额，并标注“以账单抵扣为准”。请以官方账单和店铺小票明细为准。

### 历史筛选后为什么有些记录不见了

筛选只影响列表展示，不会删除记录。检查搜索词、时间范围、设备、状态、异常和小票条件；同一类别内多选取“或”，不同类别之间取“且”。可以点筛选按钮查看当前条件，或点“清除筛选/清除搜索和筛选”恢复。切换账号或重启 App 会重置筛选。

### CSV 会导出筛选后的记录吗

不会。设置页的 CSV 导出始终包含当前账号的全部接水历史，不受历史页搜索和筛选影响。

### 为什么“未用小票”里没有未匹配账单的记录

“未用小票”只表示已匹配账单且账单没有小票抵扣。没有账单、账单未匹配或同步失败的记录请使用“账单匹配”筛选。

### 统计卡的总花费为什么不是实付

统计卡按需求使用“已支付且已匹配账单的原价”汇总，排除需付、退款中和已退款订单；它不是实际支出。实付金额仍在每条记录和详情中展示。卡片会显示原价账单覆盖率，未匹配账单不会被估算补齐。

### 为什么总用量没有单位、有些记录没算进去

历史接口返回的用量是数字字符串，没有保存单位，所以统计不标单位，也不做升/分钟换算。为避免把不同单位相加，只有纯数字会被计入；带 `L`、分钟等后缀、逗号、负数或非数字的值会跳过，并在覆盖率中显示可解析笔数。

### 平均单价怎么算

平均单价只使用同时有“可计入原价”和“纯数字用量”的记录，按“总用量 ÷ 总花费”计算“1 元 ≈ X 用量”，保留 2 位小数。任一侧为 0 时显示“—”，不会用未匹配账单或不完整数据补算。

### 历史金额和官方 App 不一致

应用展示的是请求时返回的官方账单；官方订单可能延迟更新、退款或调整优惠。若刚完成接水，可稍后点“刷新账单”重试。若仍不一致，请以官方 App 的订单详情为准，并保留订单号向官方客服核对。

### 导出的 CSV 在 Excel 中乱码

应用导出 UTF-8 BOM 文件，正常应可直接打开。若仍乱码，请使用 Excel 的“数据 → 从文本/CSV”导入并选择 UTF-8。

### 退出/删除账号会删除历史吗

切换账号不会删除历史。删除当前账号（“退出当前账号”或切换弹窗里的“删除”）会删除该账号在本机的 token、资料、资产快照和接水历史，无法撤销。只想换账号时请使用“切换账号”，不要删除。

### 如何彻底删除本机数据

在切换弹窗中删除全部账号，或直接卸载应用。删除账号会清除该账号的历史与资产缓存；卸载会删除全部本地数据。`allowBackup=false`，系统备份不会保留应用数据。

## 安全与反馈

### 提交 Issue 时可以附上请求日志吗

请先打码。日志即使经过自动脱敏，仍可能包含设备标识、订单号或响应中的其他信息。不要上传 token、手机号、完整设备 JSON、账号资产截图或未打码截图。

### 为什么应用没有广告、推送和统计

项目目标是最短路径完成接水。状态提醒使用本地前台服务通知，不接入推送或统计 SDK。

### 可以提交逆向材料或官方反编译代码吗

不可以。请勿在 Issue 或 PR 中提交官方客户端代码、接口清单、签名算法、凭据或任何敏感材料。详见[贡献指南](../CONTRIBUTING.md)。
