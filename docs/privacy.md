# 隐私说明

本文说明应用自身会处理哪些数据、为什么处理，以及用户可以如何控制。它不替代官方服务、支付宝或学校运营方的隐私政策。

## 权限

| 权限 | 用途 | 拒绝后的影响 |
| --- | --- | --- |
| `INTERNET` | 登录、设备探测、解锁、接水同步与支付查询 | 无法使用联网功能 |
| `CAMERA` | 扫描设备二维码 | 可改用相册或手动输入 |
| `NFC` | 读取标签并绑定设备 | 无法使用 NFC 流程 |
| `ACCESS_FINE_LOCATION` / `ACCESS_COARSE_LOCATION` | 构造下单风控参数 | 确认页会阻断 |
| `POST_NOTIFICATIONS` | 展示接水与支付状态通知 | 仍可接水，但可能看不到通知 |
| `FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_DATA_SYNC` | 切到后台后继续同步状态 | 接水过程可能无法持续跟踪 |

相机与 NFC 在 Manifest 中声明为非必需硬件，没有相应硬件的设备仍可安装。

## 处理的数据

| 数据 | 用途 | 保存位置与期限 |
| --- | --- | --- |
| 手机号、验证码 | 登录官方服务 | 手机号随登录请求发送；应用不单独保存手机号 |
| 登录 token | 维持登录态 | 本机 DataStore，使用 Android Keystore 的 AES-GCM 密钥加密；退出登录或卸载时删除 |
| 设备标识 | 设备识别与风控 | 本机 Android ID 经哈希后作为设备标识发送；应用不读取 OAID |
| 位置坐标 | 构造下单风控参数 | 仅在确认/下单时读取，不保存位置历史；可能作为请求参数发送给官方服务 |
| 设备与订单信息 | 探测设备、解锁、结算与支付查询 | 随请求发送给官方服务；订单结果写入本机历史 |
| 接水历史 | 本机查询与 CSV 导出 | 本机 SQLite，直到用户删除、清空或卸载 |
| 设置 | 主题、演练模式、一键解锁 | 本机 DataStore，直到清除应用数据或卸载 |
| NFC 标签映射 | 标签到设备的本地绑定 | 本机 DataStore，可在诊断页删除 |
| 调试请求日志 | Debug 构建排障 | 仅内存，最多 100 条；退出进程即丢失，Release 不记录 |

设备品牌、Android 版本、应用版本和接水会话信息会随请求发送给官方服务，用于兼容与风控。

## 网络行为

- 应用自身的网络请求只发往官方服务，不发送给广告、统计或其他第三方。
- 官方服务可能按自己的隐私政策记录请求、账号、设备与订单信息，这部分不受本应用控制。
- 应用会查询系统是否安装了原 App，以便提供跳转入口；不会读取原 App 的数据。
- 跳转支付宝小程序或原 App 后，数据处理由对应平台负责。
- 应用不集成广告 SDK、统计 SDK、推送 SDK，也不读取通讯录、短信或已安装应用列表（仅查询原 App 是否安装）。

## 本地安全

- token 使用 AndroidKeyStore 中的 AES-GCM 密钥加密，密钥不离开 Keystore。
- `allowBackup=false`，应用数据不会进入系统备份。
- 接水历史与 NFC 映射不上传；卸载应用会删除本地数据。
- Debug 请求日志会对登录凭证、手机号、验证码与定位等常见敏感字段打码，但响应体和设备标识仍可能包含敏感信息，分享前必须人工检查。
- 复制设备 JSON 或 cURL 只在用户主动点击时发生，应用不会后台写剪贴板。

## 用户控制

- 在系统设置中撤销相机、NFC、定位或通知权限。
- 在设置页清空接水历史、退出登录。
- 在诊断页删除 NFC 映射、清空请求日志。
- 卸载应用以删除全部本地数据。

撤回定位或相机权限后，相关流程会停止工作，但不会删除已有历史。

## 儿童与敏感场景

本应用面向校园饮水机用户，不面向儿童设计，也不收集年龄、健康或生物识别信息。请勿在公开渠道提交手机号、token、订单号、设备完整标识或位置坐标。

## 安全反馈

如果发现凭据泄露、token 明文存储或日志脱敏不完整，请通过 Issue 联系维护者，并在描述中避免粘贴真实敏感数据。确认问题后再私下提供必要的复现信息。
