# 隐私说明

本文说明应用自身会处理哪些数据、为什么处理，以及用户可以如何控制。它不替代官方服务、支付宝或学校运营方的隐私政策。

## 权限

| 权限 | 用途 | 拒绝后的影响 |
| --- | --- | --- |
| `INTERNET` | 登录、设备探测、解锁、接水同步与支付查询 | 无法使用联网功能 |
| `CAMERA` | 扫描设备二维码 | 可改用相册或手动输入 |
| `NFC` | 读取标签并绑定设备 | 无法使用 NFC 流程 |
| `ACCESS_FINE_LOCATION` / `ACCESS_COARSE_LOCATION` | 构造下单风控参数；已授权时在扫码页静默预热 | 确认页阻断并显示授权引导 |
| `POST_NOTIFICATIONS` | 展示接水与支付状态通知 | 仍可接水，但可能看不到通知 |
| `FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_DATA_SYNC` | 切到后台后继续同步状态 | 接水过程可能无法持续跟踪 |

相机与 NFC 在 Manifest 中声明为非必需硬件，没有相应硬件的设备仍可安装。

## 处理的数据

| 数据 | 用途 | 保存位置与期限 |
| --- | --- | --- |
| 手机号、验证码 | 登录官方服务、账号列表与重新登录 | 手机号随登录请求发送；完整手机号使用 Android Keystore 的 AES-GCM 密钥加密保存在本机，界面只显示脱敏手机号；验证码不保存 |
| 登录 token（可多个） | 维持多个账号的登录态 | 本机 DataStore，每个账号单独使用 Android Keystore 的 AES-GCM 密钥加密；删除账号或卸载时删除 |
| 账号资料 | 账号卡片与切换列表 | 昵称/本地别名、头像 URL、脱敏手机号保存在本机；资料由官方服务返回 |
| 账户余额、通用小票、积分 | 账号资产展示 | 最近一次成功加载的资产快照保存在本机 DataStore；删除账号或卸载时删除 |
| 自动积分设置 | 自动签到/任务开关 | 本机 DataStore，直到清除应用数据或卸载 |
| 自动积分运行记录 | 积分页状态与日志 | 按账号保存在本机 DataStore；仅含日期、计数、固定文案、任务码与跳过原因，不含 token、手机号、请求头或原始响应 |
| 通用小票店铺与流水 | 小票明细展示 | 店铺汇总随资产快照保存；流水按需加载，不单独持久化 |
| 设备标识 | 设备识别与风控 | 本机 Android ID 经哈希后作为设备标识发送；应用不读取 OAID |
| 位置坐标 | 构造下单风控参数 | 扫码页在已授权时静默预热，确认/下单流程读取；坐标仅在本机内存缓存 5 分钟以便复用，不写入磁盘、不保存位置历史；可能作为请求参数发送给官方服务 |
| 套餐与支付方式缓存 | 确认页优先展示并后台刷新 | 本机 DataStore（独立 `plan_cache` 文件），按设备与当前账号 `localId` 隔离；最长 7 天、最多 50 条，超出按最早抓取淘汰；删除账号或卸载时删除 |
| 设备与订单信息 | 探测设备、解锁、结算与支付查询 | 随请求发送给官方服务；订单结果写入本机历史 |
| 接水历史 | 本机查询与 CSV 导出 | 本机 SQLite，按账号隔离；直到用户删除、清空、删除账号或卸载 |
| 设置 | 主题、演练模式、一键解锁、资产隐藏、自动积分 | 本机 DataStore，直到清除应用数据或卸载 |
| NFC 标签映射 | 标签到设备的本地绑定 | 本机 DataStore，可在诊断页删除 |
| 调试请求日志 | Debug 构建排障 | 仅内存，最多 100 条；退出进程即丢失，Release 不记录 |

设备品牌、Android 版本、应用版本和接水会话信息会随请求发送给官方服务，用于兼容与风控。账号资料中的真实姓名、身份证号不会进入应用的数据模型。

## 网络行为

- 业务网络请求只发往官方服务，不发送给广告、统计或其他第三方。
- 扫码解析成功后会预取套餐与支付方式；确认页命中缓存时先展示缓存并在后台刷新，刷新失败保留旧缓存；解锁报错时清空该设备的预取缓存。
- 头像图片由资料中返回的地址直接加载。该地址可能由官方 CDN 或第三方图片服务提供；请求不携带应用登录 token 或请求签名，但图片服务仍可看到 IP、User-Agent 等常规网络信息，并可能在本地保留图片缓存。
- 官方服务可能按自己的隐私政策记录请求、账号、设备与订单信息，这部分不受本应用控制。
- 应用会查询系统是否安装了原 App，以便提供跳转入口；不会读取原 App 的数据。
- 跳转支付宝小程序或原 App 后，数据处理由对应平台负责。
- 应用不集成广告 SDK、统计 SDK、推送 SDK，也不读取通讯录、短信或已安装应用列表（仅查询原 App 是否安装）。

## 本地安全

- token 与完整手机号使用 AndroidKeyStore 中的 AES-GCM 密钥加密，密钥不离开 Keystore。
- 昵称、头像 URL、脱敏手机号、资产快照和接水历史以本机数据形式保存；应用不把它们上传到自有服务器。
- 套餐与支付方式缓存为明文 JSON，只包含设备标识、套餐与支付方式字段，不含 token、手机号或位置坐标；按账号 `localId` 隔离。
- `allowBackup=false`，应用数据不会进入系统备份。
- Debug 请求日志会对请求与响应中的登录凭证、手机号、真实姓名、身份证号、头像地址、验证码与定位等常见敏感字段打码；设备标识、订单号等仍可能包含敏感信息，分享前必须人工检查。
- 复制设备 JSON 或 cURL 只在用户主动点击时发生，应用不会后台写剪贴板。
- 删除账号会删除该账号在本机的 token、资料、资产快照、套餐缓存和接水历史；删除操作不可撤销。

## 用户控制

- 在系统设置中撤销相机、NFC、定位或通知权限。
- 在设置页切换、添加、重命名或删除账号；删除账号会删除该账号在本机的记录。
- 在设置页清空当前账号的接水历史。
- 在诊断页删除 NFC 映射、清空请求日志。
- 卸载应用以删除全部本地数据。

撤回定位或相机权限后，相关流程会停止工作，但不会删除已有历史。

本地“退出当前账号”或“删除账号”只影响本机，不会撤销服务端会话。若需要注销官方账号，请使用官方客户端的注销流程。

## 儿童与敏感场景

本应用面向校园饮水机用户，不面向儿童设计，也不收集年龄、健康或生物识别信息。请勿在公开渠道提交手机号、token、订单号、设备完整标识或位置坐标。

## 安全反馈

如果发现凭据泄露、token 明文存储或日志脱敏不完整，请通过 Issue 联系维护者，并在描述中避免粘贴真实敏感数据。确认问题后再私下提供必要的复现信息。
