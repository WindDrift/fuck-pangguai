# 积分与自动积分

积分页是底部导航的第三个页签，顺序为：扫码 / 历史 / 积分 / 设置。它只作用于当前登录账号。

## 积分页

- **积分余额**：显示当前账号积分，并按 `400 积分 ≈ 1 元` 给出参考价值。实际抵扣金额以收银台展示为准。
- **签到**：显示今日是否已签到；未签到时可以手动签到，自动积分也会在运行时处理签到。
- **积分自动抵扣**：默认关闭。开启后，解锁饮水机时读取官方积分抵现规则；当前账号有积分、已开通自动使用积分且没有风控验证时，自动在解锁请求中带上积分优惠。
- **自动积分**：包含总开关、启动检查、自动刷积分、直接任务实验、运行状态和“立即运行”。
- **任务列表**：显示全部任务。标准模式只有无需广告、H5、验证码或外部跳转的安全任务可以手动完成；开启自动刷积分后，全部积分任务都可在页面上手动完成或由运行阶段尝试。
- **运行日志**：保留最近一段运行记录，只包含时间、固定文案、任务码和跳过原因。

## 积分自动抵扣

- 解锁前会并行读取 `userIntegral/limitRule` 与 `userIntegral/checkUserIsRisk`，不阻塞确认页展示。
- 只有 `integralTotal > 0` 且 `isUserIntegral` 为真时才尝试抵扣；账号未开通自动抵扣、没有积分或需要验证时，只在确认页显示原因，不影响解锁。
- 尝试抵扣时把解锁请求的积分优惠标记从 `-8`（不使用）改为 `8`（使用积分），与官方收银台开关一致；最终抵扣金额、比例和是否成功由官方服务计算，客户端不自行计算。
- 抵扣检查失败或超时会按“不使用积分”继续解锁，不会阻断接水。
- 切换设备或退出确认页会丢弃上一台设备的抵扣检查结果。

## 自动积分的默认值

- 自动积分总开关：**关闭**。
- 启动 App 时检查：**开启**，但只有总开关或自动刷积分开启后才生效。
- 自动刷积分：**关闭**。开启后尝试任务列表中的全部积分任务与子任务，并按剩余次数重试；遇到验证码立即停止。
- 直接任务实验：**关闭**。标准模式下只尝试极少数无广告、无 H5、无需验证码且通知权限已开启的通知类任务。
- 首次开启总开关或自动刷积分会显示风险确认。自动积分不会在后台服务中运行，只在 App 启动、回到前台或进入积分页时检查。

## 运行规则

- App 启动或回到前台时，如果总开关或自动刷积分开启、启动检查开启，且当天尚未尝试，则运行一轮。
- 进入积分页时也会检查；同一天最多自动运行一次。
- “立即运行”不受总开关限制，但要求已登录，且仍遵守验证码阈值和请求间隔。
- 标准模式：签到后尝试首页浏览子任务和少量安全任务，最多尝试 5 个任务。
- 刷积分模式：签到后循环完成首页浏览的待完成子任务，再遍历任务列表中的全部积分任务；有子任务的按子任务顺序完成，无子任务的在剩余次数内重试（单个任务本轮最多 3 次，总共最多 30 次）。广告、H5、外部跳转类任务也会尝试完成上报，服务端是否认可由其风控决定。
- 切换账号会取消当前运行；每个账号有独立的每日记录。
- 签到完成即视为当天自动运行完成；任务列表失败不会自动重试，之后可在积分页手动重跑。
- 单个任务遇到验证码会跳过；连续两次遇到验证码会停止任务阶段。程序不会绕过验证码、伪造广告回调或自动提交 H5。
- 通知权限未开启时不会尝试通知类任务；非积分奖励或达到次数上限的任务不会被完成。
- 自动积分不会并行操作多个账号。

## 小票与接水账单

- 接水历史会尝试匹配官方账单中的通用小票抵扣（1 点 = 0.01 元），并在记录中显示对应店铺、消耗点数、抵扣金额与本金/赠送拆分。
- 只有账单确有通用小票抵扣时才显示小票区块；未使用小票的订单不会显示空的小票金额。
- 小票流水按订单号匹配。若流水暂时查不到或请求失败，仍以账单内的抵扣金额为准，并标注“店铺流水未匹配”或“获取失败”。
- 账单的原价、各项优惠与实付均来自官方订单数据；本应用不会自行重算优惠或改写小票余额。

## 限制与风险

- 任务和积分由官方服务返回与判定。即使请求成功，也不代表积分一定到账；页面会把“请求结果”和“实际余额”分开显示。
- 自动刷积分会对广告、H5、外部跳转类任务直接调用任务完成接口；服务端可能拒绝、静默不加分或触发风控。程序不加载广告、不伪造广告回调，也不绕过验证码。
- 积分自动抵扣是否生效由官方服务计算；显示“将使用 N 积分”只表示客户端已按规则带上积分优惠，不代表订单一定减免。
- 任务列表可能因账号、设备或服务端策略返回为空；此时签到仍可单独使用。
- 自动签到、刷积分或积分抵扣可能违反服务条款并触发账号风控。请只在自己的账号上低频使用，并自行评估风险。
- 积分页的日志保存在本机并按账号隔离，不包含 token、手机号、请求头或原始响应。删除账号后这些记录可能仍作为无敏感内容的小型键保留，清除应用数据或卸载即可删除。

## 验证范围

- 已通过 JVM 单元测试：任务分类（含刷积分模式）、每日守卫、签到/任务状态机、账号切换、验证码阈值、运行记录序列化、积分抵扣资格判定、解锁请求的积分优惠标记。
- 需要真机或真实账号验证：通知权限、Activity 前后台触发、DataStore 跨进程持久化、服务端任务列表结构、广告/H5 任务完成接口是否接受、积分是否实际到账，以及积分抵扣是否在真实订单中生效。
