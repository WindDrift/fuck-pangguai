# 文档索引

这里记录安装、使用、构建、调试与架构说明。所有文档均面向公开仓库，只描述行为与设计，**不包含接口地址、请求头、签名算法、官方反编译代码或任何真实凭据**。

## 普通用户

| 文档 | 适合阅读的场景 |
| --- | --- |
| [使用指南](usage.md) | 第一次安装、登录、添加/切换账号、查看账号资产与小票、扫码或碰 NFC、确认套餐、查看接水状态与历史 |
| [常见问题](faq.md) | 登录失效、多账号切换、资产刷新、头像、定位被拒、BLE 设备、支付状态未知、通知或 CSV 问题 |
| [隐私说明](privacy.md) | 想了解应用申请哪些权限、保存哪些账号/资产数据、头像请求与业务请求发往哪里 |
| [免责声明](disclaimer.md) | 使用前确认风险与责任边界 |

## 阅读顺序

1. 普通用户：使用指南 → 常见问题。
2. 首次构建：构建指南 → 调试指南 → 测试与验收。
3. 参与开发：架构说明 → 贡献指南 → 测试与验收。
4. 发布版本：发布指南。

文档描述 1.x 版本的行为。界面、设备兼容性和支付流程可能随官方服务调整，遇到差异时以实际运行结果为准。
