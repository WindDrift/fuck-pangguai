# 使用指南

本文面向普通用户，介绍从安装到完成一次接水的完整流程。

> 本项目是非官方客户端，与胖乖生活、学校及设备运营方无关联。使用前请阅读[免责声明](disclaimer.md)。

## 安装与系统要求

- Android 12（API 31）及以上。
- 从 [GitHub Releases](https://github.com/WindDrift/fuck-pangguai/releases) 下载 APK，或按[构建指南](build.md)自行编译。
- 自行构建的包与公开 Release 签名不同，不能直接覆盖安装。切换来源前请先备份需要保留的记录。

应用会按需申请以下权限：

| 权限 | 用途 | 是否必需 |
| --- | --- | --- |
| 相机 | 扫描设备二维码 | 扫码时必需，可改用相册或手动输入 |
| NFC | 读取标签并绑定设备 | 仅 NFC 流程需要 |
| 精确定位 | 构造下单风控参数；已授权时在扫码页静默预热 | 确认页要求，拒绝后无法继续 |
| 通知 | 展示接水状态 | 可选，拒绝后仍可接水但看不到状态通知 |
| 前台服务 | 切到后台后持续同步接水与支付状态 | 接水过程中使用 |

## 首次启动

1. 阅读并接受免责声明。未接受前不会进入登录页。
2. 输入手机号和短信验证码登录。验证码由官方服务发送。
3. 登录成功后进入“扫码”页。登录凭证与账号资料保存在本机，下次启动会自动登录。
4. Debug 构建的登录页还提供“粘贴 token”入口，仅用于开发调试，见[调试指南](debug.md)。

## 账号与资产

设置页顶部展示当前账号卡片：

- **资料**：头像、昵称、脱敏手机号；头像加载失败或没有头像时显示昵称首字。
- **资产**：账户余额、通用小票、积分，以及通用小票的本金/赠送拆分。`100 点通用小票 = 1 元`。
- **右上角图标**：刷新、隐藏/显示资产、切换账号。隐藏偏好会保存在本机。
- **小票明细**：设置页“账号 → 通用小票明细”是单独一行入口；点击进入店铺列表，再点店铺进入流水页。收入为 `+`，支出为 `-`。
- **刷新**：进入设置页会自动刷新；也可以点卡片右上角的刷新图标。刷新失败时保留上次数据并提示。

### 添加账号

1. 点击账号卡片右上角的切换账号图标，或设置页“账号 → 添加账号”。
2. 输入另一个账号的手机号与验证码。
3. 登录成功后，新账号会被加密保存在本机并自动切换；原账号不会丢失。

Debug 构建仍可在登录页粘贴 token 添加账号；Release 不提供该入口。

### 切换、重命名与删除

- 点击“切换账号”，账号按最近使用时间排序。点击有效账号直接切换。
- 每行“改名”只修改本机显示名称，不会同步到服务器。
- 每行“删除”会删除该账号在本机的 token、资料、接水历史、资产缓存与套餐缓存，无法撤销。
- 账号登录失效时会显示“已失效”。点击它会要求重新验证码登录；其他有效账号不受影响。
- 接水进行中不允许切换或删除账号，避免旧会话使用新账号的凭证。

### 退出当前账号

“退出当前账号”会删除本机保存的当前账号 token、资料、接水历史、资产缓存与套餐缓存；若还有其他有效账号，会自动切换到最近使用的那个，否则返回登录页。它不会撤销服务端会话，也不能替代官方的注销流程。

## 识别设备

### 扫码

1. 在“扫码”页将设备二维码放入取景框。
2. 识别成功后会进入确认页。相机权限被拒绝时，可从相册选择二维码图片，或切换到手动输入。
3. 手动输入支持二维码原文、NQT、SN 或 IMEI；不确定设备标识时优先使用二维码原文。

### NFC

1. 确认系统 NFC 已开启，并允许应用读取 NFC。
2. 将手机靠近标签，应用会解析标签中的设备信息。
3. 首次遇到的标签会提示绑定。绑定时会保存标签 ID 与设备 SN、名称和商品 ID 的映射。
4. 绑定关系保存在本机。更换标签、设备或学校后可能需要重新绑定。

### 支付宝小程序兜底

部分设备或场景会提供跳转支付宝小程序的入口。该流程由外部应用完成，本应用只负责打开入口，不参与小程序内的操作与支付。

## 确认页

确认页会展示设备名称、当前套餐、支付通道和风险提示。开始接水前请核对：

- **设备状态**：`isBluetooth=1` 的 BLE 设备当前不可解锁；设备故障码（例如 4204）会直接阻断并给出提示。
- **定位**：确认页需要定位权限。套餐与支付方式会优先从本机缓存展示并在后台刷新；定位未完成时底部按钮不可用，定位失败可点“重试定位”，套餐仍可查看。演练模式不要求定位。
- **套餐**：选择需要的出水量或套餐；不同设备提供的选项可能不同。
- **支付通道**：按设备支持的渠道选择。后付费设备可能不显示即时支付。
- **演练模式**：开启时只展示将要发送的请求，不真实解锁。Debug 构建默认开启，正式使用前请在设置中关闭。
- **一键解锁**：默认关闭。开启后仍需在同一设备完成过一次确认，后续扫码才会直接进入解锁。
- **跳过设备信息**：默认关闭。开启后扫码或碰一碰识别成功会直接进入确认页，不再弹出设备信息；可与一键解锁组合实现扫码即开。首次遇到的新 NFC 标签仍会先询问是否绑定。

确认后会创建一次接水会话。请勿连续点击开始，应用会阻止重复创建。

## 接水与结算

1. 解锁成功后进入“使用中”页面，展示实时水量、阶段和订单号。
2. 应用会启动前台服务，即使切到后台也会持续同步设备状态。
3. 结束接水后，应用会触发设备结算并查询支付结果。部分设备需要在设备上手动结束。
4. 状态通知会一直保留到本次会话结束。通知权限被拒绝时，仍可通过应用内页面查看进度。
5. 支付状态长时间未知时，页面会提示回到原 App 核对，不会自动重复扣款或重试支付。

如果设备只支持在原 App 内结束，使用中页面会给出对应提示。请按设备或原 App 的指引完成结束操作，再回到本应用查看结果。

## 接水历史与账单

- 历史记录保存在本机 SQLite，不会上传，并按账号隔离。
- 历史页只显示当前账号的记录；切换账号后列表随之切换。
- 记录会尝试匹配官方账单，并在列表和详情中直接展开，不需要再点一次“展开”：
  - **原价**：账单原始金额。
  - **优惠明细**：逐项列出通用小票以外的优惠；支付优惠单独一行。
  - **通用小票**：仅当账单确有通用小票抵扣时显示，包含店铺、消耗点数、抵扣金额，以及能匹配到流水时的本金/赠送拆分。
  - **实付**：按官方“实付款”口径显示，小票与其他优惠只作为明细，不会从实付里重复扣减。
- 默认自动同步最近 90 天的账单。更早的记录会在打开详情或下拉刷新时按需匹配；已同步的账单会随记录保留，离线也能查看。
- 下拉刷新可继续同步剩余账单；列表顶部会显示同步进度或待同步数量。不做跨记录合计，每笔接水单独显示。
- 如果账单已有小票抵扣、但店铺流水未匹配或加载失败，仍会显示账单内的抵扣金额，并标注“以账单抵扣为准”。
- 找不到对应账单的记录不会被删除，也不会用本地“用量”冒充金额；页面会标注“未找到对应账单”，可以点“同步账单”或“刷新账单”重试。
- 可查看单条详情、删除单条记录。
- 导出 CSV 与清空记录只作用于当前账号，入口在“设置 → 数据”。
- 清除历史不可撤销。卸载应用也会删除本机记录与账单缓存。

## 积分与自动积分

底部导航第三个页签是“积分”，只作用于当前账号。

- **积分余额**：显示积分和按 `400 积分 ≈ 1 元` 计算的参考价值；实际抵扣以收银台为准。
- **签到**：显示今日签到状态；手动签到与自动运行都会使用当前账号。
- **任务**：显示全部任务。只有无广告、无 H5、无验证码、无外部跳转的安全任务可以手动完成；其他任务会显示跳过原因。
- **自动积分**：默认关闭。开启后可设置“启动 App 时检查”和“直接任务实验”；进入积分页也会检查。同一天最多自动运行一次，失败后需手动重跑。
- **立即运行**：不受自动开关限制，但仍要求已登录，并遵守安全分类和请求间隔。
- **跳过规则**：广告、H5、验证码、外部跳转、通知权限未开启、非积分奖励或达到次数上限的任务不会自动完成。连续两次遇到验证码会停止任务阶段。

自动积分只在 App 启动、回到前台或进入积分页时检查，不使用后台服务，也不并行操作多个账号。自动签到或任务可能违反服务条款并触发账号风控，请自行评估。完整说明见[积分与自动积分](points.md)。

## 设置

- **账号卡片**：头像、昵称、脱敏手机号、账户余额、通用小票（本金/赠送）、积分；右上角图标支持刷新、隐藏/显示和切换账号。
- **通用小票明细**：账号分组内的独立入口，进入店铺列表后可继续查看店铺流水。
- **主题**：跟随系统、浅色或深色。
- **动态取色**：开启后跟随系统壁纸（Monet）；关闭时使用 Miuix 默认蓝色。
- **悬浮底栏**：底部导航以悬浮胶囊样式显示，页面切换带过渡动画。
- **一键解锁**：同一设备首次确认成功后，后续扫码可直接解锁。
- **演练模式**：只展示请求，不真实调用解锁。
- **添加账号**：登录另一个账号，当前账号会保留。
- **导出 CSV**：将当前账号的全部接水记录导出为 CSV 文件，使用 UTF-8 BOM，Excel 打开中文一般不会乱码。
- **清空接水历史**：删除当前账号在本机的记录。
- **退出当前账号**：删除本机当前账号并自动切换或返回登录页。

连续点击“版本”7 次会进入隐藏诊断页，详见[调试指南](debug.md)。诊断页面向排障，普通使用无需进入。

## 遇到问题时

先查看[常见问题](faq.md)。提交 Issue 时请附上应用版本、设备型号、Android 版本和复现步骤，并对日志中的手机号、token、订单号和设备标识打码。请勿上传完整请求日志或任何凭据。
