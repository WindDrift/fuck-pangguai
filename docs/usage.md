# 使用指南

本文面向普通用户，介绍从安装到完成一次接水的完整流程。

> 本项目是非官方客户端，与胖乖生活、学校及设备运营方无关联。使用前请阅读[免责声明](disclaimer.md)。

## 安装与系统要求

- Android 12（API 31）及以上。
- 从 [GitHub Releases](https://github.com/WindDrift/fuck-pangguai/releases) 下载 APK，或按[构建指南](build.md)自行编译。
- 自行构建的包与公开 Release 签名不同，不能直接覆盖安装。切换来源前请先备份需要保留的记录。

应用会按需申请以下权限：

| 权限 | 用途 | 是否必需 |
| --- | --- | --- |
| 相机 | 扫描设备二维码 | 扫码时必需，可改用相册或手动输入 |
| NFC | 读取标签并绑定设备 | 仅 NFC 流程需要 |
| 精确定位 | 构造下单风控参数；已授权时在扫码页静默预热 | 确认页要求，拒绝后无法继续 |
| 通知 | 展示接水状态 | 可选，拒绝后仍可接水但看不到状态通知 |
| 前台服务 | 切到后台后持续同步接水与支付状态 | 接水过程中使用 |

## 首次启动

1. 阅读并接受免责声明。未接受前不会进入登录页。
2. 输入手机号和短信验证码登录。验证码由官方服务发送。
3. 登录成功后进入“扫码”页。登录凭证与账号资料保存在本机，下次启动会自动登录。
4. Debug 构建的登录页还提供“粘贴 token”入口，仅用于开发调试，见[调试指南](debug.md)。

## 账号与资产

设置页顶部展示当前账号卡片：

- **资料**：头像、昵称、脱敏手机号；头像加载失败或没有头像时显示昵称首字。
- **资产**：账户余额、通用小票、积分，以及通用小票的本金/赠送拆分。`100 点通用小票 = 1 元`。
- **右上角图标**：刷新、隐藏/显示资产、切换账号。隐藏偏好会保存在本机。
- **小票明细**：设置页“账号 → 通用小票明细”是单独一行入口；点击进入店铺列表，再点店铺进入流水页。收入为 `+`，支出为 `-`。
- **刷新**：进入设置页会自动刷新；也可以点卡片右上角的刷新图标。刷新失败时保留上次数据并提示。

### 通用小票充值

通用小票充值目前只支持支付宝，且取决于店铺是否开通支付宝通道。

1. 打开“设置 → 账号 → 通用小票明细”，点击店铺右侧的“充值”；也可以在店铺流水页顶部点击“充值”。
2. 充值页会显示当前店铺的小票余额、本金/赠送与退款说明。选择一个官方面额；面额上的“送 ¥x”为额外赠送，“到账 x 点”为实际到账点数。
3. 点击“确认充值”，在弹窗中核对店铺、面额、赠送与支付方式，确认后创建官方虚拟订单。
4. 在订单页点击“立即支付 ¥x”，应用会调起支付宝。未安装支付宝时，支付宝 SDK 会尝试 H5 收银台。
5. 支付完成后，应用会向官方服务核验订单状态；只有服务端确认已支付才显示“支付成功”，并自动刷新资产与小票流水。
6. 如果暂时无法确认结果，会显示“支付结果确认中”。此时请不要重复支付；可以点击“重新查询”，或返回店铺后重新进入充值页查询。待确认订单会在本机保留 2 小时。
7. 如果未完成支付，页面会显示“未完成支付”，可重新选择面额；如果订单超时关闭，则需重新下单。

进入店铺充值时，如果存在同一账号、同一店铺的待确认订单，页面会显示待确认提示，只提供“查询状态”，不会自动再次支付。

退款不在客户端范围内：页面只展示官方返回的退款说明；需要退款时请联系官方客户端、商家或学校运营方。真实扣款与到账请以官方订单和支付宝账单为准。

### 添加账号

1. 点击账号卡片右上角的切换账号图标，或设置页“账号 → 添加账号”。
2. 输入另一个账号的手机号与验证码。
3. 登录成功后，新账号会被加密保存在本机并自动切换；原账号不会丢失。

Debug 构建仍可在登录页粘贴 token 添加账号；Release 不提供该入口。

### 切换、重命名与删除

- 点击“切换账号”，账号按最近使用时间排序。点击有效账号直接切换。
- 每行“改名”只修改本机显示名称，不会同步到服务器。
- 每行“删除”会删除该账号在本机的 token、资料、接水历史、资产缓存、待确认充值订单与套餐缓存，无法撤销。
- 账号登录失效时会显示“已失效”。点击它会要求重新验证码登录；其他有效账号不受影响。
- 主动退出并选择“保留记录”的账号会显示“已退出”，记录仍保存在本机；点击后重新验证码登录同一手机号，原记录会继续显示。
- 接水进行中不允许切换或删除账号，避免旧会话使用新账号的凭证。

### 退出当前账号

当前账号有接水记录时，“退出当前账号”会先让你选择处理方式：

- **保留记录并退出**：清除本机 token 与资产、套餐等缓存，保留账号条目和接水记录；账号在切换面板显示“已退出”，重新登录同一手机号后记录仍可查看。
- **先导出 CSV**：打开系统保存面板导出当前账号的全部记录；导出完成后回到退出选择，再决定保留或删除。
- **删除记录并退出**：删除 token、资料、接水历史、资产缓存、待确认充值订单与套餐缓存，无法撤销。

没有记录时仍直接确认退出，并删除账号数据。若还有其他有效账号，会自动切换到最近使用的那个，否则返回登录页。退出不会撤销服务端会话，也不能替代官方的注销流程。

## 识别设备

### 扫码

扫码页顶部会按时段问候当前账号：优先使用本地别名，其次昵称、脱敏手机号，最后显示「同学」。进入主界面后应用会静默检查 GitHub Releases；发现新版本时右上角显示「新版本可用」，点击可查看更新说明并前往 Release 下载页。没有更新或检查失败时不会提示。

1. 默认进入“扫码”页会自动打开相机。开启“不自动打开相机”后，页面先显示待机界面；NFC 已开启时显示“NFC 读取已就绪”，点“扫描二维码”才申请相机权限并启动相机。同一会话内切换标签页或从确认/接水页返回会自动恢复相机。
2. 将设备二维码放入取景框。
3. 识别成功后会进入确认页。相机权限被拒绝时，可从相册选择二维码图片，或切换到手动输入。
4. 手动输入支持二维码原文、NQT、SN 或 IMEI；不确定设备标识时优先使用二维码原文。

### NFC

1. 确认系统 NFC 已开启，并允许应用读取 NFC。扫码页底部胶囊显示“NFC 未开启，点此开启”时，点击可跳转系统 NFC 设置；设备没有 NFC 硬件时不显示该提示。
2. 将手机靠近标签，应用会解析标签中的设备信息。
3. 首次遇到的标签会提示绑定。绑定时会保存标签 ID 与设备 SN、名称和商品 ID 的映射。
4. 绑定关系保存在本机。更换标签、设备或学校后可能需要重新绑定。
5. 已绑定的标签可在「设置 → 使用 → 管理 NFC 标签」查看标签 ID、SN、商品 ID 和绑定时间，或删除失效绑定。设备支持但未开启 NFC 时仍可进入管理页，页内提供跳转系统设置的按钮。

### 支付宝小程序兜底

部分设备或场景会提供跳转支付宝小程序的入口。该流程由外部应用完成，本应用只负责打开入口，不参与小程序内的操作与支付。

## 确认页

确认页会展示设备名称、当前套餐、支付通道和风险提示。开始接水前请核对：

- **设备状态**：`isBluetooth=1` 的 BLE 设备当前不可解锁；设备故障码（例如 4204）会直接阻断并给出提示。
- **定位**：确认页需要定位权限。套餐与支付方式会优先从本机缓存展示并在后台刷新；定位未完成时底部按钮不可用，定位失败可点“重试定位”，套餐仍可查看。演练模式不要求定位。
- **套餐**：选择需要的出水量或套餐；不同设备提供的选项可能不同。
- **支付通道**：按设备支持的渠道选择。后付费设备可能不显示即时支付。进入确认页后会在后台预绑定当前选中的后付费通道，以减少点击“开始使用”后的等待；预绑定不扣款，也不会跳过“开始使用”确认。
- **解锁加速**：在设置中选择“不启用 / 保守 / 激进 / 丧心病狂”，只影响点击后的通道绑定等待与设备就绪轮询频率，不改变套餐、支付方式、unlock 参数或结算逻辑。
- **演练模式**：开启时只展示将要发送的请求，不真实解锁。Debug 构建默认开启，正式使用前请在设置中关闭。
- **一键解锁**：默认关闭。开启后仍需在同一设备完成过一次确认，后续扫码才会直接进入解锁。
- **跳过设备信息**：默认关闭。开启后扫码或碰一碰识别成功会直接进入确认页，不再弹出设备信息；可与一键解锁组合实现扫码即开。首次遇到的新 NFC 标签仍会先询问是否绑定。
- **管理 NFC 标签**：查看和删除本机的标签绑定；设备不支持 NFC 时隐藏入口，NFC 未开启时仍可进入管理。

确认后会创建一次接水会话。请勿连续点击开始，应用会阻止重复创建。

## 接水与结算

1. 解锁成功后进入“使用中”页面，展示实时用量、阶段和订单号；设置水量换算后，会在用量下方并列显示换算水量和杯数。
2. 应用会启动前台服务，即使切到后台也会持续同步设备状态。
3. 结束接水后，应用会触发设备结算并查询支付结果。部分设备需要在设备上手动结束。
4. 状态通知会一直保留到本次会话结束，并按设置显示换算水量与杯数。通知权限被拒绝时，仍可通过应用内页面查看进度。
5. 支付状态长时间未知时，页面会提示回到原 App 核对，不会自动重复扣款或重试支付。

如果设备只支持在原 App 内结束，使用中页面会给出对应提示。请按设备或原 App 的指引完成结束操作，再回到本应用查看结果。

## 接水历史与账单

- 历史记录保存在本机 SQLite，不会上传，并按账号隔离。
- 历史页只显示当前账号的记录；切换账号后列表随之切换。
- 设置 → 使用 → 水量换算可配置“多少用量对应多少 mL”，一杯容量可选。配置后列表、详情与统计会并列显示换算水量；未配置时只显示原始用量。
- 记录会尝试匹配官方账单，并在列表和详情中直接展开，不需要再点一次“展开”：
  - **原价**：账单原始金额。
  - **优惠明细**：逐项列出通用小票以外的优惠；支付优惠单独一行。
  - **通用小票**：仅当账单确有通用小票抵扣时显示，包含店铺、消耗点数、抵扣金额，以及能匹配到流水时的本金/赠送拆分。
  - **实付**：按官方“实付款”口径显示，小票与其他优惠只作为明细，不会从实付里重复扣减。
- 默认自动同步最近 90 天的账单。更早的记录会在打开详情或下拉刷新时按需匹配；已同步的账单会随记录保留，离线也能查看。
- 下拉刷新可继续同步剩余账单；列表顶部会显示同步进度或待同步数量。筛选栏下方的统计卡会汇总当前列表，详见下文“筛选结果统计”。
- 如果账单已有小票抵扣、但店铺流水未匹配或加载失败，仍会显示账单内的抵扣金额，并标注“以账单抵扣为准”。
- 找不到对应账单的记录不会被删除，也不会用本地“用量”冒充金额；页面会标注“未找到对应账单”，可以点“同步账单”或“刷新账单”重试。
- 可查看单条详情、删除单条记录。
- 导出、导入与清空记录只作用于当前账号，入口在“设置 → 数据”。
- 导入仅接受本应用导出的 CSV。记录写入当前账号，订单号重复的行自动跳过；状态、错误与结算单号会尽量还原，无法识别的状态按用量归为“已支付”或“已结束（无费用）”。
- 导入完成后会立即刷新历史，并按现有规则尝试匹配 90 天内的账单；更早的记录仍可在打开详情或下拉刷新时按需同步。
- 清除历史不可撤销。卸载应用也会删除本机记录与账单缓存。

### 搜索与筛选

- 历史页顶部固定搜索栏和筛选按钮。搜索会匹配设备、订单号、账单店铺/设备、支付方式、优惠标签、小票备注、错误信息，以及页面可见的金额与点数；不会匹配账号内部 ID 或本地合成订单号。
- 筛选按钮打开底部弹窗，所有修改立即生效；“重置”清空筛选但保留搜索词，“完成”关闭弹窗。筛选按钮角标显示启用的筛选类别数，搜索栏下方显示可单独删除的条件标签和“清除筛选”。
- 支持以下筛选：
  - **时间**：全部、今天、近 7 天、近 30 天、近 90 天，或自定义起止日期；按列表卡片显示的时间筛选，自定义日期包含起止当天，也允许只填一端。
  - **设备**：多选当前账号历史中出现过的设备；支持弹窗内搜索、全选可见和清除。
  - **接水结果**：已支付、未扣费、支付未知、设备异常。
  - **账单匹配**：已匹配、未匹配、同步失败、未同步。
  - **账单支付状态**：需付、已支付/完成、退款中、已退款。
  - **异常/失败**：会话错误、账单同步失败或小票流水失败任一命中。
  - **通用小票**：全部、已用小票、未用小票；还可按流水是否匹配、小票店铺、本金/赠送构成和小票抵扣金额区间筛选。
  - **实付金额**：人民币最小值/最大值，包含边界；空的一端表示不限。
- 同一类别内多选取“或”，不同类别之间取“且”；搜索词与其他条件也取“且”。
- “未用小票”只包含已匹配账单且没有小票抵扣的记录；无账单或账单未匹配的记录请用“账单匹配”筛选。
- 筛选只影响列表显示，不会改变账单自动同步、删除或 CSV 导出；CSV 始终导出当前账号的全部记录。账单同步进行中，依赖账单的筛选结果可能随同步完成而变化。
- 筛选状态在切换底部页签后保留；切换账号或重启 App 会恢复为未筛选状态。没有匹配结果时可点“清除搜索和筛选”一键恢复。

### 筛选结果统计

历史页在筛选栏下方固定展示一张统计卡，随搜索、筛选和账单同步实时更新；当前没有可见记录时隐藏。

- **总花费（按原价）**：只汇总“账单已匹配”且账单状态为已支付/已完成（官方状态 2/3）的订单原价，排除需付、支付超时、退款中、已退款和同步失败旧账单。它不是实付金额；卡片会显示“已支付且已匹配 X / 可见 Y 笔”的覆盖率。
- **总用量**：汇总当前可见记录中的所有纯数字用量，不改变原始数值，也不标单位。带 `L`、分钟等后缀、逗号、负数或非数字的值会跳过；卡片显示“可解析 X / 可见 Y 笔”。退款、需付和无账单记录只要用量是纯数字也计入总用量。设置水量换算后，卡片会整行展示原始用量，并在下方并列显示总水量与杯数。
- **总水量**：仅在设置水量换算后显示。纯数字用量按比例换算，带 `L`、`mL`、`升`、`毫升` 的记录直接计入；配置了一杯容量时再汇总杯数。带分钟等非水量单位的记录会跳过。
- **平均单价**：设置换算后同时显示每元用量、每元水量和杯数。每元用量只使用“可计入原价 + 纯数字用量”的记录；每元水量使用“可计入原价 + 可换算水量”的记录，两个覆盖数不同时分别标注。未设置换算时仍只显示“1 元 ≈ X 用量”。
- 统计只作用于当前筛选结果，不改变账单同步、删除或 CSV 导出；账单同步完成时，统计数字可能随之变化。修改换算比例后，列表与统计会立即按新比例重算；CSV 仍只导出原始用量。

## 积分与自动积分

底部导航第三个页签是“积分”，只作用于当前账号。

- **积分余额**：显示积分和按 `400 积分 ≈ 1 元` 计算的参考价值；实际抵扣以收银台为准。
- **签到**：显示今日签到状态；手动签到与自动运行都会使用当前账号。
- **任务**：显示全部任务。只有无广告、无 H5、无验证码、无外部跳转的安全任务可以手动完成；其他任务会显示跳过原因。
- **自动积分**：默认关闭。开启后可设置“启动 App 时检查”和“直接任务实验”；进入积分页也会检查。同一天最多自动运行一次，失败后需手动重跑。
- **立即运行**：不受自动开关限制，但仍要求已登录，并遵守安全分类和请求间隔。
- **跳过规则**：广告、H5、验证码、外部跳转、通知权限未开启、非积分奖励或达到次数上限的任务不会自动完成。连续两次遇到验证码会停止任务阶段。

自动积分只在 App 启动、回到前台或进入积分页时检查，不使用后台服务，也不并行操作多个账号。自动签到或任务可能违反服务条款并触发账号风控，请自行评估。完整说明见[积分与自动积分](points.md)。

## 设置

- **账号卡片**：头像、昵称、脱敏手机号、账户余额、通用小票（本金/赠送）、积分；右上角图标支持刷新、隐藏/显示和切换账号。
- **通用小票明细**：账号分组内的独立入口，进入店铺列表后可继续查看店铺流水。
- **主题**：跟随系统、浅色或深色。
- **动态取色**：开启后跟随系统壁纸（Monet）；关闭时使用 Miuix 默认蓝色。
- **悬浮底栏**：底部导航以悬浮胶囊样式显示，页面切换带过渡动画。
- **不自动打开相机**：默认关闭。开启后进入扫码页先显示待机界面，点击按钮才启动相机，可提升冷启动速度；推荐同时开启系统 NFC。
- **一键解锁**：同一设备首次确认成功后，后续扫码可直接解锁。
- **解锁加速**：默认“保守”。不启用恢复 1.13.1 之前的点击时绑定通道、同步保存确认设备并固定每秒轮询；保守为预绑定通道、前 2 秒每 250ms 轮询、之后每秒；激进在预绑定未完成时不再等待，前 3 秒每 100ms 轮询、之后每 250ms；丧心病狂额外并行查询设备是否已启动，前 3 秒每 50ms 轮询、之后每 100ms。激进与丧心病狂会明显增加请求频率，可能触发服务端限流，且“设备已启动”信号可能早于 msgSync 确认，建议只在网络稳定时试用。
- **水量换算**：配置“多少用量对应多少 mL”，一杯容量可选。可先用已知容量的杯子或瓶子接一次水，按容器容量和接水前后的用量差值填写；留空或“清除换算”会恢复原始用量显示。规则对所有账号生效，修改后历史记录即时重算。
- **演练模式**：只展示请求，不真实调用解锁。
- **添加账号**：登录另一个账号，当前账号会保留。
- **导出 CSV**：将当前账号的全部接水记录导出为 CSV 文件，使用 UTF-8 BOM，Excel 打开中文一般不会乱码。
- **导入 CSV**：从本应用导出的 CSV 恢复接水记录；重复订单号自动跳过，导入后立即尝试匹配账单。
- **清空接水历史**：删除当前账号在本机的记录。
- **退出当前账号**：有记录时可选择保留、先导出或删除；保留后账号显示为已退出，重新登录同一手机号可继续查看记录。
- **关于**：进入关于页查看版本、开发者、检查更新、源码/发行/反馈链接、特别致谢、开源许可与隐私说明。

连续点击关于页的版本号 7 次会进入隐藏诊断页，详见[调试指南](debug.md)。诊断页面向排障，普通使用无需进入。

## 关于

- 顶部展示应用图标、完整名称、副标题与版本号；长按版本号可复制版本信息。Android 13 及以上显示 OS3 流体背景，Android 12 使用纯色头部；滚动时头部会淡出。
- 开发者卡片展示 GitHub 头像、公开姓名与账号，点击打开个人主页。
- 「检查更新」会查询 GitHub Releases：已是最新、发现新版本或显示失败原因；自动检查失败不会打扰。
- 源码、发布版本和问题反馈会打开对应的 GitHub 页面。
- 「特别致谢」列出 REA，胖乖生活软件的逆向分析工作由其支持。
- 「开源许可与致谢」展示 GPL-3.0 摘要、主要开源组件与第三方 SDK，并可打开完整许可证。
- 「免责声明与隐私」在应用内展示非官方说明、账号数据与使用风险，并可打开完整隐私说明。
