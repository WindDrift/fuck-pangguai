# 使用指南

本文面向普通用户，介绍从安装到完成一次接水的完整流程。

> 本项目是非官方客户端，与胖乖生活、学校及设备运营方无关联。使用前请阅读[免责声明](disclaimer.md)。

## 安装与系统要求

- Android 12（API 31）及以上。
- 从 [GitHub Releases](https://github.com/WindDrift/fuck-pangguai/releases) 下载 APK，或按[构建指南](build.md)自行编译。
- 自行构建的包与公开 Release 签名不同，不能直接覆盖安装。切换来源前请先备份需要保留的记录。

应用会按需申请以下权限：

| 权限 | 用途 | 是否必需 |
| --- | --- | --- |
| 相机 | 扫描设备二维码 | 扫码时必需，可改用相册或手动输入 |
| NFC | 读取标签并绑定设备 | 仅 NFC 流程需要 |
| 精确定位 | 构造下单风控参数 | 确认页要求，拒绝后无法继续 |
| 通知 | 展示接水状态 | 可选，拒绝后仍可接水但看不到状态通知 |
| 前台服务 | 切到后台后持续同步接水与支付状态 | 接水过程中使用 |

## 首次启动

1. 阅读并接受免责声明。未接受前不会进入登录页。
2. 输入手机号和短信验证码登录。验证码由官方服务发送。
3. 登录成功后进入“扫码”页。登录凭证保存在本机，下次启动会自动登录。
4. Debug 构建的登录页还提供“粘贴 token”入口，仅用于开发调试，见[调试指南](debug.md)。

退出登录会清除本机保存的登录凭证，但不会自动删除接水历史。

## 识别设备

### 扫码

1. 在“扫码”页将设备二维码放入取景框。
2. 识别成功后会进入确认页。相机权限被拒绝时，可从相册选择二维码图片，或切换到手动输入。
3. 手动输入支持二维码原文、NQT、SN 或 IMEI；不确定设备标识时优先使用二维码原文。

### NFC

1. 确认系统 NFC 已开启，并允许应用读取 NFC。
2. 将手机靠近标签，应用会解析标签中的设备信息。
3. 首次遇到的标签会提示绑定。绑定时会保存标签 ID 与设备 SN、名称和商品 ID 的映射。
4. 绑定关系保存在本机。更换标签、设备或学校后可能需要重新绑定。

### 支付宝小程序兜底

部分设备或场景会提供跳转支付宝小程序的入口。该流程由外部应用完成，本应用只负责打开入口，不参与小程序内的操作与支付。

## 确认页

确认页会展示设备名称、当前套餐、支付通道和风险提示。开始接水前请核对：

- **设备状态**：`isBluetooth=1` 的 BLE 设备当前不可解锁；设备故障码（例如 4204）会直接阻断并给出提示。
- **定位**：确认页需要定位权限。拒绝权限或无法取得位置时不能继续。
- **套餐**：选择需要的出水量或套餐；不同设备提供的选项可能不同。
- **支付通道**：按设备支持的渠道选择。后付费设备可能不显示即时支付。
- **演练模式**：开启时只展示将要发送的请求，不真实解锁。Debug 构建默认开启，正式使用前请在设置中关闭。
- **一键解锁**：默认关闭。开启后仍需在同一设备完成过一次确认，后续扫码才会直接进入解锁。

确认后会创建一次接水会话。请勿连续点击开始，应用会阻止重复创建。

## 接水与结算

1. 解锁成功后进入“使用中”页面，展示实时水量、阶段和订单号。
2. 应用会启动前台服务，即使切到后台也会持续同步设备状态。
3. 结束接水后，应用会触发设备结算并查询支付结果。部分设备需要在设备上手动结束。
4. 状态通知会一直保留到本次会话结束。通知权限被拒绝时，仍可通过应用内页面查看进度。
5. 支付状态长时间未知时，页面会提示回到原 App 核对，不会自动重复扣款或重试支付。

如果设备只支持在原 App 内结束，使用中页面会给出对应提示。请按设备或原 App 的指引完成结束操作，再回到本应用查看结果。

## 接水历史

- 历史记录保存在本机 SQLite，不会上传。
- 可查看单条详情、删除单条记录或清空全部记录。
- 支持导出 CSV，文件使用 UTF-8 BOM，Excel 打开中文一般不会乱码。
- 清除历史不可撤销。卸载应用也会删除本机记录。

## 设置

- **主题**：跟随系统、浅色或深色。
- **动态取色**：开启后跟随系统壁纸（Monet）；关闭时使用 Miuix 默认蓝色。
- **一键解锁**：同一设备首次确认成功后，后续扫码可直接解锁。
- **演练模式**：只展示请求，不真实调用解锁。
- **清空接水历史**：删除本机全部记录。
- **退出登录**：清除本机登录凭证并返回登录页。

连续点击“版本”7 次会进入隐藏诊断页，详见[调试指南](debug.md)。诊断页面向排障，普通使用无需进入。

## 遇到问题时

先查看[常见问题](faq.md)。提交 Issue 时请附上应用版本、设备型号、Android 版本和复现步骤，并对日志中的手机号、token、订单号和设备标识打码。请勿上传完整请求日志或任何凭据。
